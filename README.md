# URL Analyzer

Description
The URL Analyzer is a beginner-friendly Java project that analyzes and processes URLs using basic string manipulation and control structures. This project demonstrates fundamental programming concepts such as loops, condition checking, and string handling in Java.

Features
- Validates whether a given URL is properly formatted  
- Extracts key components such as protocol, domain name, and path  
- Performs basic analysis using simple logic and string operations  
- Lightweight and easy to understand for beginners  

Tech Stack
- Java  
- IntelliJ IDEA  

How It Works
The program takes a URL as input and uses Java string methods along with loops and conditional statements to:
1. Check if the URL starts with a valid protocol (http/https)  
2. Identify and extract the domain name  
3. Analyze the structure of the URL  

Purpose
This project was developed as part of learning core Java concepts and building logical thinking for real-world problem solving. It is suitable for beginners who want to understand how string parsing works in Java.

How to Run
1. Clone the repository  
2. Open the project in IntelliJ IDEA  
3. Run the main Java file  
4. Enter a URL input when prompted
